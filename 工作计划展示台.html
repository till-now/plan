云端同步（多设备）

在 Supabase 建一张表，各设备填同一组「项目地址 + 公开密钥 + 团队码」，进度就自动互通。数据存在你自己的 Supabase 项目里。

第一次用？点这看 4 步配置说明
  1. 打开 supabase.com 注册并新建项目（免费额度够个人用）。
  2. 左侧 SQL Editor → New query → 粘贴上方「建表 SQL」→ Run。
  3. 左侧 Settings → API，复制 Project URL 与 anon public 两个值填到上面。
  4. 自己起一个团队码填上（所有设备必须一致），点「保存设置」→「立即同步」。

只能填 anon public 密钥（它本就设计为公开）；不要填 service_role 密钥。
